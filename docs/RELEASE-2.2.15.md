# Hélène 2.2.15

Update setup now gives unresolved source conflicts to your selected agent, with paginated diffs and exact fragment patches. The incoming application's independent reviewers still check the finished candidate before installation continues. A separate merger model is no longer started by this setup path.

Older installations whose agent tools cannot apply fragment patches receive an explicit clean-code option that keeps the selected data folder and archives the previous source. Setup never selects clean code automatically. Windows destination-path and active-runner fixes from prior releases are retained.

## Install

Extract the whole ZIP and open `helene.exe` (Windows), `Helene.app` (macOS Apple silicon), or `Start Helene.sh` (Debian/Ubuntu or Fedora x86_64). Select the old installation and current data folder. Keep the previous program until setup completes.
