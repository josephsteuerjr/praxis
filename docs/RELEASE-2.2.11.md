# Hélène 2.2.11

One setup wizard for first launch, migration and Update on Windows, macOS and Linux.

- Create an agent, connect an existing data folder, combine previous code with the incoming release and review it with the new Python panel, or install clean code while keeping your data.
- Choose the program and data locations. Previous source and Git are retained; optional old-program cleanup follows confirmed startup.
- Restore pristine upstream code from the button beside Update. Cold startup now waits for standard-library initialization before starting desktop owner threads.

## Install

Download and extract the application archive for your platform. Keep the extracted folder together: Python and the ready runtime are included.

| Platform | Download | Open |
| --- | --- | --- |
| Windows x64 | [Application ZIP](https://github.com/josephsteuerjr/praxis/releases/download/v2.2.11/Helene-2.2.11.zip) | `helene.exe` |
| macOS Apple silicon | [Application ZIP](https://github.com/josephsteuerjr/praxis/releases/download/v2.2.11/Helene-2.2.11-macos-arm64.zip) | `Helene.app` |
| Debian/Ubuntu x86_64 | [Application ZIP](https://github.com/josephsteuerjr/praxis/releases/download/v2.2.11/Helene-2.2.11-linux-x86_64.zip) | `Start Helene.sh` |
| Fedora x86_64 | [Application ZIP](https://github.com/josephsteuerjr/praxis/releases/download/v2.2.11/Helene-2.2.11-fedora-x86_64.zip) | `Start Helene.sh` |

The reusable entry is `app/helene_setup.py`, launched with the bundled Python. Whisper and XTTS downloads remain optional in Settings.

## Evidence and licenses

`SHA256SUMS`, per-archive SHA files and `release-evidence.json` identify the exact files and distinguish source checks, native synthetic-profile acceptance and inherited runtime qualification. Physical user acceptance and real service-credential prompts are separate from those checks.

Every application ZIP includes full Apache terms, the relay's MIT license with original author unluckyjori and current attribution, and the separate XTTS CPML terms under `licenses/helene/`. Optional voice assets are copied without changing their pinned bytes.
