# Hélène 2.2.16

Fixes setup copying its own locked WebView cache into a program update. Browser profiles and temporary window-control files are excluded from both overlay preparation and validation.

The incoming build can now temporarily provide the existing Python agent with the new diff/patch update hand. Its runner restarts to load the hand; the same agent resolves frozen conflicts, and the incoming independent panel checks the result. No additional merger model is started. The previous hand is backed up and restored after preparation or cancellation. Stop remains binding. If the old application cannot expose runner control, setup offers the explicit clean-code option with the existing data folder.

## Install

Extract the entire ZIP and open `helene.exe` (Windows), `Helene.app` (macOS Apple silicon), or `Start Helene.sh` (Debian/Ubuntu or Fedora x86_64). Select the old application and current data folder; keep the previous installation until setup completes.
