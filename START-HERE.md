# Hélène — исходники выпуска

[Карта кода](desk/resources/HELENE-MAP.md) показывает связь исходников, установленной программы и данных профиля. [Комплект выпуска](release/README.md) содержит команды для сборки и проверки.

В исходном ZIP откройте `RELEASE-ORIGIN.json`. Сверьте поле `commit` с коммитом тега издателя, затем восстановите отдельную рабочую копию:

```sh
python release/kit.py restore --commit <полный-SHA-коммита> --to ../helene-work
```

В Git-клоне уже есть история. Для первой проверки перейдите в рабочую копию, измените текст карты, выполните `git diff --check`, сохраните изменение отдельным коммитом и соберите исходный ZIP командой `python release/kit.py source --out ../out`. Откройте карту из полученного архива и сравните её с рабочим файлом. Для проверки установленного окна и ядра следуйте руководству выпуска.
