# Карта исходников Hélène

Версию, платформу, точный Git-коммит и SHA-256 этого документа записывает сборщик в RELEASE-ORIGIN.json рядом с START-HERE.md. В исходном ZIP карта находится в desk/resources/HELENE-MAP.md, в настольной и серверной программах — в app/resources/HELENE-MAP.md. Редактируйте копию в исходниках, чтобы доставить обновлённую карту со следующим выпуском.

| Что меняете | Где искать в исходниках | Как проверить |
|---|---|---|
| Ядро, ход, память, инструменты | praxis/ — базовые модули; helene/core/ — файлы издания с приоритетом при совпадении пути. Правило выбора задаёт desk/installer/portable_sources.py, функция compose_core. | В настольном ZIP состав дерева tree/ записан в code-upstream.json. В серверном — в SERVER-SOURCE.json. В тестовой копии импортируйте изменённый модуль отдельным процессом Python. |
| Конкретный агент | helene.json задаёт tree (дерево данных) и code (код). Реестр и разрешение путей — desk/localharness/agents.py. У дополнительных профилей свой agents/<id>/helene.json. | Относительное tree разрешается у конфига профиля. В каталоге данных находятся memory/, soul/, workspace/ и настройки модели memory/llm.json. Их содержимое принадлежит профилю. |
| Программа, окно и процессы | desk/python_app.py, desk/localharness/python_controller.py, desktop_supervisor.py и runner.py; HTTP-канал desk/deskapp.py и desk/deskd/. В ZIP код программы находится в app/, интерпретатор настольной версии — в runtime/. | Изменения Python подхватывает новый процесс. Для опыта используйте отдельную копию приложения и отдельный профиль. |
| Интерфейс окна | desk/app/src/, общие компоненты desk/ui-kit/, словари desk/lang/. | Сборка в desk/app/dist/ попадает в app/static/. Отметьте DOM-элемент в исходном TS, найдите отметку в JS готового архива, откройте тестовую копию окна. |
| Mini App, мобильный, удалённый и установочный интерфейсы | desk/miniapp/, desk/mobile/, desk/remote/, desk/setup/ui/. Команды в package.json каждого проекта. | Выходы miniapp/dist/, mobile/dist/, remote/dist/, setup/dist/ относительно desk/. Мобильный и Mini App находятся в app/mobile/ и app/miniapp/. Комплект выпуска записывает хеши результатов пяти сборок. |
| Тесты и проверка состава | desk/tests/, desk/app/test/, тесты ядра рядом с его модулями. В настольном архиве verification/repository/ содержит исходники и тесты, verification/manifest.json — их опись, verification-tools/ — инструменты этой платформы. | Сначала прогоните тест изменённого компонента. Проверьте результат и на конечном ZIP. |
| Сервер Linux ARM64 | В архиве Helene/ находятся tree/, app/, server/, helene.json, requirements.txt и relay-product/. Команды запуска описаны в server/README-СЕРВЕР.md. | Для проверки запуска нужны Linux ARM64 и зависимости из server/. Для редактирования и сборки возьмите точный исходный ZIP, указанный в корневом START-HERE.md. |
| Следующий выпуск | release/kit.py, release/inputs.json и release/README.md в исходном ZIP. Платформенные сборщики находятся в desk/installer/. | Восстановите родительский коммит через kit.py restore. Следующий коммит проверяйте из отдельной рабочей копии. kit.py build связывает готовый ZIP с коммитом, картой и платформой. |

Практическая проверка Python на Windows: в извлечённой тестовой копии создайте tree/map_probe.py с одной строкой `print("map-probe")`, затем выполните `runtime\python.exe tree\map_probe.py`. На настольных POSIX-системах используйте `runtime/bin/python3 tree/map_probe.py`. Сборка изменённого фронта и публикация тестовых активов описаны в release/README.md исходного ZIP.
