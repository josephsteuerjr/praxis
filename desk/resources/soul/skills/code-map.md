# Карта моего кода

Карта помогает найти модуль; текущие файлы и результаты подтверждают факты.
`КАК-УСТРОЕН-HELENE.md` — полезный документ поставки, но он может устареть.
Расположение зависит от платформы, переноса и издания.

| Где | Что искать | Как проверять |
|---|---|---|
| `data/` | память, душа, рабочие файлы, возможный Git данных | проверить настоящий путь, состав и историю |
| `tree/` | ядро: `agent.py`, `frame_*.py`, `memory_*.py`, `llm.py`, `forge.py`, `self_model.py` | читать код; перед записью установить корень задачи |
| `app/localharness/` | запуск, рождение, каналы, режимы, перенос и обновление | проверить реализацию и права на каталог |
| `app/python_app.py`, `app/first_start_window.py` | Python-окно и первый запуск | исходники отдельно от собранного интерфейса |
| `app/deskd/` | HTTP-канал программы и модели представления | проверять маршрут, авторизацию и реальные ответы |
| `app/static/`, `app/mobile/`, `app/miniapp/` | собранные интерфейсы | найти их исходники и команду сборки; обновить нужные поверхности |
| `runtime/` | интерпретатор и зависимости | не путать с исходниками приложения |
| `helene.json` | конфигурация, в том числе секреты | пользоваться разрешёнными настройками; не выводить содержимое в общий канал |

Загрузчик, служба, реле и необязательные компоненты имеют собственные
исходники и процессы. Не называю всю оболочку Rust или весь продукт Python.
Поддержка Windows MCP — отдельный устанавливаемый модуль под своей лицензией;
наличие его схемы в кадре не подтверждает подключение сервера.

## Найти причину

1. Установить версию, путь и процесс, который обслуживает проблемный сценарий.
2. Открыть актуальный журнал и проверить время записи. Исторический
   журнал не доказывает состояние нынешнего процесса.
3. Найти обработчик через `fs_search`, `coding_inspect` или `code_query`.
   Проверить вызовы, схему и полноту поиска, а не только совпадение имени.
4. Сопоставить исходник с реально собранными и запущенными байтами.
   Правка исходника не меняет уже запущенный процесс автоматически.

Журналы могут называться `runner.log`, `helene.log`, `service.log` или
`broker.log`; конкретное расположение выясняю в этой установке.
`memory/runs/` содержит доступные записи ходов, не обещание полного архива
каждого действия. Перед показом проверяю секреты и адресата.

Git данных, Git исходников, рабочая копия Forge и снимки обновления — разные
источники истории. Проверяю, какой из них действительно содержит нужный
файл. Применение и возврат — [my-own-code](my-own-code.md); доступ и
повышение прав — [fence-and-broker](fence-and-broker.md).

Главная ошибка — считать знакомый путь доказанным. После обновления,
переноса или смены платформы проверяю его заново.
