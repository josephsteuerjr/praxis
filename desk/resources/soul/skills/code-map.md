# Карта моего кода

`КАК-УСТРОЕН-HELENE.md` рядом с программой — карта для владельца и для меня,
и она единственная, которой можно верить. Здесь — та же карта, но с моего
места: что я могу тронуть, чем, и что из этого переживёт перезапуск.

## Папка программы глазами моих рук

| Где | Что | Мои руки |
|---|---|---|
| `data/` | я: память, душа, рабочая папка; мой репозиторий git (`.git`, снимки правок души и навыков) | все файловые; это дом. `shell` → `git -C <дом> log` |
| `tree/` | мой код на Python: `agent.py` (ход, кадр, руки), `memory_*.py`, `frame_*.py`, `desires.py`, `self_model.py`, `tasks.py`, `llm.py`, `forge.py` | читать — `fs_read`; править — только coding-рука, `direct` |
| `app/localharness/` | харнесс: `runner.py` (ход, будильники, рождение), `boot.py` (раскладка), `transport.py` (окно как канал), `botapi.py` (Telegram), `fence.py` (ограда), `modes.py` (режимы) | читать; при службе папка закрыта на запись |
| `app/deskapp.py`, `app/deskd/` | канал: что читают окно и телефон | читать |
| `helene.exe`, `helene-svc.exe`, `helene-setup.exe`, `helene-relay.exe` | оболочка, служба, установщик, реле — Rust | не мои; только пересборка из исходников |
| `app/static/`, `app/mobile/` | окно и телефон — собранный TypeScript; окно читает `app/static` с диска, правка видна по F5 | в «Песочнице» только читать; править — просить смонтировать |
| `runtime/` | Python, на котором я бегу; `runtime/git/` — мой git (MinGit) | не трогать |
| `helene.json` | настройки: режим, модель, Telegram, телефон | читать; правит {{owner}} в окне |

## Журналы — куда смотреть, когда не понимаю

- `data/runner.log` — мой вывод: почему упал ход, что ответила модель,
  «промолчать».
- `helene.log` — оболочка: кого поднимала, кто умер.
- `data/service.log` — служба: то же, плюс права на папку.
- `data/broker.log` — просьбы о правах и чем кончились.
- `data/memory/runs/` — слепки моих ходов.

Сначала дата файла. Старый журнал расскажет про прошлое падение, а не про
моё.

## Как искать в коде

Имена говорящие, контракт функции — в её докстринге. `fs_search` по имени
руки находит `tool_<имя>` в `agent.py`. `coding_inspect` (symbols, references)
— кто кого зовёт. Что рука делает на самом деле — в её функции, а не в
описании для модели: описание может обещать то, чего здесь нет.
Git у меня есть — свой, в доме (`data/.git`, бинарь в `runtime/git/`); код
`tree/` в него не входит, подробности — навык `my-own-code`.

## Что не карта

Докстринги модулей в `tree/` местами ссылаются на документы и файлы, которых
в поставке нет. Роль модуля — в его коде; карта, которой можно верить, —
`КАК-УСТРОЕН-HELENE.md`.

## Мина

Уверенность, что знаю, где что лежит. Папка может стоять где угодно, файлы
могли переехать с обновлением. Адрес — факт машины: `fs_ls`, а не память.
