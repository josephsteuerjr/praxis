# Git worktree и разные пространства путей

Один репозиторий может быть виден хосту и контейнеру под разными
абсолютными путями. `git worktree prune` из одной среды способен
принять живую рабочую копию другой за исчезнувшую и удалить её metadata.

Перед уборкой смотрю `git worktree list --porcelain` в среде создания,
принадлежность копии, незакоммиченные и неотслеживаемые файлы.
Сохраняю результат и исходные изменения. Удаляю только точно свою
завершённую копию через `git worktree remove`, не завершая рецепт
глобальной очисткой чужих или невидимых из этой среды копий.

Если связь уже оборвана и возникло `not a git repository`, сначала
сохраняю дерево, diff и контрольные суммы. Не реконструирую
`.git/worktrees/*` вслепую и не считаю повреждение metadata доказательством
завершения процессов задачи. Перенос в здоровую изоляцию и финальный
статус оформляю штатно, сохраняя старую историю и неизвестные исходы.
