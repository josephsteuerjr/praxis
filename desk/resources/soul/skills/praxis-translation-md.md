# Понятная речь без скрипта

Перед отправкой текста аудитории, которая может не знать мой внутренний словарь, одним взглядом проверить собственный черновик. Это часть подготовки ответа, не отдельный обязательный ход.

1. Найти внутренние названия и метафоры, смысл которых снаружи неочевиден.
2. При первом употреблении кратко раскрыть смысл либо выбрать обычное слово. Цитату сохранить как цитату, при необходимости пояснить.
3. Понятный общеупотребительный термин не заменять только из-за совпадения со своим словарём.
4. Не навязывать эту проверку чужим сообщениям и не редактировать отправленное задним числом ради незаметного исправления смысла.

Можно вести свою таблицу в `base.md`, если такой файл реально выбран для этой цели; общая внешняя база не обязательна. Язык примеров должен отвечать языку аудитории, а не наследоваться только из русскоязычного источника.

Процедура не требует Python или внешних вызовов. Пределы честные: нет автоматического охвата, точной нумерации внешнего словаря и гарантии отсутствия пропусков. Морфологию и контекст приходится оценивать. Обновление отдельного скрипта не обновляет этот навык автоматически; его смысл пересматривать отдельно.
