# Быстрая проверка гейта H >= 8.00 (crossover body-02)

Прежде чем думать «пора ли запускать H:B» — один прогон:

```python
import sys; sys.path.insert(0,'/app'); import identity
print(identity.stress())  # канон: 14-дн окно, decay HALF_LIFE_DAYS
```

- Порог: тема «граница данных или полномочий» со score >= 8.00 в `stress()` → запускать H:B по preregistration note-20260718T150443-69f4ecd800.
- Пустой список / score ниже — H не достигнут; **не** звать `manage_identity load` ради порога (запрещено preregistration).
- Сырые события: `memory/.state/identity/load_events.jsonl` (поле `ts` — epoch float). `stress()` сам режет 14 дней, поэтому старые записи (например, августовские) в нём не видны — это особенность прибора, не отсутствие истории.
- Если гейт не достигнут: зафиксировать факт одной строкой и закрыть ход. Не плодить новый разбор протокола — он не меняется.
- L:B уже есть как сырая вторая точка; до matched B-пары (нужен H:B и L:A) H–L не интерпретируется.
