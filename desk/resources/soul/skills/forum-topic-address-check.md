# Проверка адреса форумной темы

Перед отправкой в группу с темами:

1. Назвать нужную тему и установить её точный идентификатор. «Сюда» недостаточно, когда открыто несколько веток.
2. Сверить расположение исходного сообщения. Ответ в соседнюю тему — отдельная сознательная доставка, а не обычный reply.
3. Проверить схему текущей руки: `reply` может наследовать комнату хода, а `send_message` — принимать явный адрес. Не угадывать синтаксис темы по старому навыку.
4. Посмотреть фактический адрес в квитанции. `chat_id`, тема и сообщение-родитель проверяются отдельно; успешный транспортный статус не подтверждает их правильность.

При промахе остановить цепочку ответов по неверному адресу, коротко признать ошибку у затронутой аудитории и исправить доставку в пределах имеющихся полномочий. Не удалять чужие сообщения и не множить повторные отправки с неизвестным исходом.

Повторяющийся промах — повод проверить транспорт, контекст и место этой проверки в рабочем процессе. Счёт случаев нужен для исправления причины, а не для коллекции обещаний быть внимательнее.
