# Подписка ChatGPT через Relay

Это маршрут подключения, не вечный снимок релиза. Сначала установить продукт, ОС и версию: встроенный relay Hélène и отдельный praxis-relay для Ouroboros имеют разные управление и поставку.

Для Hélène использовать штатный раздел подписок и предлагаемый им вход в свой аккаунт. Не ставить второй relay и не останавливать встроенный ради старого меню из памятки. Названия пунктов, поддерживаемые сборки и способ входа брать из текущего приложения.

Для отдельного клиента:

1. Проверить официальный текущий релиз и документацию. Скачать подходящую ОС/архитектуре сборку; не обещать отсутствующий артефакт.
2. Завершить доступный OAuth/device-вход в собственный аккаунт. Учётные данные не пересылать; необходимость внешнего Python проверять по версии, не объявлять универсальной.
3. Запустить relay и оставить его работающим для клиента.
4. В Ouroboros выбрать поддерживаемый OpenAI-compatible провайдер и фактический локальный base URL. `http://127.0.0.1:5011/v1` — пример стандартного адреса отдельного relay, не адрес удалённого компьютера и не гарантия настройки Hélène.
5. Требование к ключу и префиксу модели проверить по клиенту/relay. Не использовать чужой действующий токен как декоративную строку. Доступные модели сверять через `/v1/models`, не по старому списку названий.

Диагностика по необходимости: `/health` проверяет локальный сервер, `/v1/limits` — доступные сведения о лимитах. Рабочий health не доказывает успешный ответ провайдера. При лимите поддерживаемое переключение между уже авторизованными аккаунтами может помочь; не воспроизводить частично выполненный запрос и не обещать бесконечную ёмкость. Если все подходящие лимиты исчерпаны, показать причину и срок восстановления, когда известен.

Перед остановкой отличить свой standalone-процесс от relay приложения и иных сервисов. Отзывать доступ штатным способом; не стирать произвольный каталог auth по старому пути.

Это неофициальный мост к собственному ChatGPT-аккаунту, не OpenAI API-аккаунт и не превращение Claude-подписки в Anthropic API. Сведения о тарифах и upstream могут изменяться; при помощи человеку проверять актуальные первичные источники.
