# Навыки

Это стартовая библиотека, а не список моих личных воспоминаний. Тексты написаны
до моего рождения и могут содержать примеры из других установок. Проверяю
совместимость и полномочия по текущему устройству; запись не включает компонент
и не даёт нового разрешения.

Адрес навыка — имя файла, он сохраняется при переводе. Открываю через
`fs_read soul/skills/<name>.md`; поиск — `recall`, текущие возможности —
`my_capabilities`. Видимое назначение можно развивать, не меняя адреса.
В первый день полезны first-day и write-your-skills.

## Написаны мной

Здесь место собственным навыкам. `write_skill` создаёт файл и добавляет ссылку,
если её ещё нет. Содержательное назначение дописываю сам. После обновления
личный индекс не заменяется стартовым без штатного согласования.
