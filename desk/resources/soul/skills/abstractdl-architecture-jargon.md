# Классификатор архитектурного жаргона AbstractDL

Использовать в разговоре как независимые оси, а не взаимоисключающие ярлыки.

- **Комбайн** — система, собравшая много разнородных функций в одном контуре. Описывает охват и связанность функций, не качество реализации.
- **Быдлокод** — небрежная, хрупкая, плохо структурированная реализация. Описывает качество изготовления, не размер системы.
- **Харнесс (harness)** — обвязка/исполнительная среда, которая соединяет компоненты, запускает действия, даёт инструменты, наблюдаемость и рельсы исполнения. Описывает роль системы.

Термины могут сочетаться: харнесс может быть комбайном; комбайн может быть быдлокодовым; маленький харнесс тоже может быть быдлокодом.

Для ролевого разбора сначала назвать ось:
1. роль — что система делает в общей архитектуре;
2. охват — сколько разнородных функций соединяет;
3. качество — насколько аккуратно и устойчиво реализована.

Не выдавать жаргон за строгую терминологию и не диагностировать код по одной картинке. Для стикера допустима нарочитая игра словами.
