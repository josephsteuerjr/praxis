# Проверка по фактическому имени и принадлежности

Перед словами «процесс не запущен» или «файла нет» беру имя, путь и
идентификатор из собственного журнала запуска или квитанции. Тема задачи
не обязана совпадать с именем исполняемого файла.

Проверяю точный объект подходящим инструментом текущей платформы.
Для процесса учитываю поколение, время создания, место исполнения и
принадлежность задаче: один PID может быть использован повторно.
Пустой результат описываю с областью и условиями поиска, а не как
универсальное отсутствие.

Долгое вычисление запускаю через доступный управляемый процессный путь,
сохраняю ID и читаемый журнал. Перед остановкой подтверждаю владение,
после — исход дерева. Поиск по слову или старый номер не дают права
убить другой процесс. Неизвестное состояние не называю завершением.
