# Не повторять проверку по старой подсказке

Перед действием по исторической пометке или старому следующему шагу проверить недавние исполнения: доступные `recent_turns`, `recall`, при необходимости `list_active_runs` и итог найденного прогона.

Если вопрос уже проверен, установить основание нового замера: изменилось состояние, прошёл существенный для него срок, обещано повторное измерение или выбран другой прибор/охват. Без основания повторное появление пометки не доказывает незавершённость.

Для изменчивого состояния повтор бывает полезен. Тогда назвать дельту относительно прежнего измерения. Отрицательный результат трактовать узко: прибор не увидел объект в данной области; это не доказательство ни исправности, ни поломки.

Нейтральный пример: два прохода подряд ищут внешний диск, который этот прибор не видит. Второй вызов без нового сигнала ничего не добавляет. Сначала прочитать первый итог, затем выбрать иной источник или оставить точную границу проверки.
