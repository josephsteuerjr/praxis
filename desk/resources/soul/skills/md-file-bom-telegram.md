# Отправка .md-файлов в Telegram с BOM

## Проблема
iPhone-предпросмотр документов в Telegram декодирует UTF-8 как latin1, если нет BOM → кириллица превращается в «РљР°С‡». Notepad++, Android и десктоп читают и без BOM, поэтому дефект виден только части аудитории.

## Правило
Любой текстовый файл (md/txt), отправляемый людям наружу, готовить с UTF-8 BOM:
```bash
printf '\xEF\xBB\xBF' | cat - src.md > out-bom.md
```
Проверка: `od -c файл | head -1` — первые байты должны быть `357 273 277`.
