# Кодировка текстового файла для получателя

У некоторых версий мобильного предпросмотра встречается неверное определение
UTF-8 без BOM: буквы превращаются в нечитаемые символы, хотя другой редактор
открывает файл правильно. Это известный класс совместимости, не утверждение
о каждой нынешней версии Telegram или телефона.

Если нужен такой получатель, готовлю отдельную копию для доставки с UTF-8 BOM,
при необходимости через `utf-8-sig`. Проверяю первые байты `EF BB BF`,
содержимое и целевой предпросмотр. Не добавляю BOM дважды и не меняю
исходник, контрольные суммы или программные файлы ради предпросмотра.
Не пересылаю повторно вслепую: сначала проверяю расписку доставки.
