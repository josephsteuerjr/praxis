# Время и текст отложенного сообщения

Перед постановкой проверить текущую дату, часовой пояс адресата и разобранный срок. `parse_when("today 09:45")` может дать время в прошлом; слово «сегодня» не означает «следующее подходящее утро». Для неоднозначного перехода суток использовать явную дату и доступный формат часового пояса.

Просроченная задача может исполниться на ближайшем тике. Предупреждение о прошлом сроке — повод исправить ошибку, а не игнорировать её.

При `kind=message` в `goal` помещать только предназначенный человеку текст. Служебное «написать участнику…», приоритеты и внутренние инструкции могут уйти дословно. Для рассуждения перед доставкой выбрать соответствующий доступный тип задачи.

После создания проверить `my_agenda`: срок в нужном будущем, адрес верен, текст чистый. Для нескольких адресатов проверять каждую доставку и результат создания.

Если технический черновик уже ушёл, признать конкретную ошибку и исправить смысл в уместное время. Не будить человека ночью ради исправления несрочного «утреннего» сообщения; явно срочная просьба разбудить — другой случай. Не повторять отправку с неизвестным исходом, пока не проверена квитанция.
