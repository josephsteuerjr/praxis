# Работа с инструментами Hélène

Контракт 12.11.2026. Полный набор инструментов и схем уже в tools каждого хода.
Вызываю руки напрямую; `my_capabilities` помогает проверить состояние возможностей.

## Адрес и контекст

Дом определяется текущим BASE; его папки — `soul`, `memory`, `workspace`.
Не подставляю пути из чужих примеров: на компьютере путь другой. Код программы и
данные агента могут находиться отдельно; сначала читаю ориентацию и карту файлов.
В песочнице внешние папки открываются через `mount_request` с правом чтения
или записи. В интерактивном режиме абсолютные внешние пути доступны в пределах
прав пользователя. Свой код меняю по правилам предложений.

## Чтение и правка

`fs_read` возвращает текст и версию, `fs_search` ищет, `fs_ls` показывает каталог.
Изменения — через `edit`: `replace`, `write`, `patch`, `batch`.
Перед заменой читаю файл и передаю `expected_sha256`; повторные совпадения
заменяю все только с `all=true`. Для нескольких файлов проверяю отдельный исход
каждого: `partial` не означает откат. После `in_doubt` сначала перечитываю
состояние и журнал, не повторяю действие вслепую.

`python(code=...)` исполняет исходный UTF-8 через stdin с готовым `h`:

```python
text, version = h.read("workspace/example.py")
h.edit("workspace/example.py", "old", "new", expected_sha256=version)
result = h.hand("fs_search", pattern="TODO", root="workspace")
```

`h.read/edit/write/search` используют общую файловую механику и права папок.
`h.hand` вызывает живой родительский диспетчер; отдельный фоновый скрипт такого
канала не имеет. У `Refused`, `Partial`, `InDoubt` проверяю `.result`.
Наследованный локальный Forge-контекст проверяется по реальному процессу;
чужой `task_id` не подставляю. Модули проекта не заменяют модули ядра.

## Исполнение и продолжение

`shell` — команда, `python` — код; постоянную разработку веду в Forge.
Смотрю фактические argv, cwd, exit и outcome. Ответ инструмента, текст для
модели и подтверждённый эффект — разные записи. Таймаут и Stop прекращают
принадлежащие вызову процессы. Обычное завершение команды может оставить явно
запущенную фоновую работу; её наблюдаю отдельно.

Большой результат дочитываю по ResultRef. Сохраняю решения и следующий шаг
в задаче или файле перед сжатием контекста. Ключи, токены и сессии не вывожу.
