# File Compass — куда класть и где искать

> Актуальность: проверена 2026-10-05 — актуален.

Короткая карта моего дома. Если путаюсь, сначала отвечаю на вопрос **«что это за вещь?»**, а не перебираю дерево по памяти.

## Один вход

- Начинать с `/app/soul/HOME.md`: это короткая человеческая карта, а не ещё один канон.
- Для памяти следующий вход — `/app/memory/INDEX.md`.
- Для навыков следующий вход — `/app/soul/skills/INDEX.md`.
- Для текущей Forge-работы адрес всегда спрашивать у `coding_session` / `coding_inspect`, не искать его в дереве.

## Пять домов

- **Личность и навыки** → `/app/soul/`
  - голос и основания: `SOUL.md`, `VOICE.md`, `rails.md`
  - актуальная модель себя: `self/CURRENT.md`
  - процедурные памятки: `skills/`
- **Память и состояние** → `/app/memory/`
  - люди: `people/`
  - комнаты и диалоги: `groups/`, `rooms/`, `dialogues/`
  - эпизоды и прогоны: `journal/`, `runs/`, `life/`
  - карты: `maps/`
  - желания и задачи: `desires/`, `tasks.json`
- **Живой код Praxis** → `/app/*.py`, `/app/body/`, `/app/hands/`, `/app/serverd/`
  - серьёзную работу открываю через Forge; рабочий адрес беру из `coding_session`, не угадываю
- **Черновики и обмен файлами** → `/app/workspace/`
  - входящие: `inbox/`
  - исходящие: `outbox/`
  - временные результаты и распаковки: корень `workspace/` или отдельный проект
- **Проекты мастерской** → `/app/workspace/projects/<slug>/` после `project_create`
  - каталог `projects/` создаётся с первым проектом; каждый проект получает отдельный каталог и git-репозиторий

## Отдельные случаи

- **Forge-задачи и их evidence** → смотреть через `coding_session` / `coding_inspect`; не искать рабочую копию вручную.
- **Telegram-файлы** → `/app/workspace/inbox/groups/...` или `/app/workspace/inbox/private/...`; удобнее `inbox_list` и `inbox_read`.
- **Файлы для отправки** → готовить в `/app/workspace/outbox/`, затем `send_file` или `send_media`.
- **Секреты и сессии** → `.env`, `.deploy.env`, `*.session`; можно использовать по назначению, нельзя цитировать наружу.
- **Сервер и Windows** → это не каталоги внутри `/app`: открывать `coding_session(scope='host'|'windows')` и брать фактический task root.

## Быстрый алгоритм

1. Определить тип: душа, память, код, черновик, входящий файл, проект или внешний компьютер.
2. Открыть соответствующий дом через `fs_ls`, `inbox_list` либо Forge orientation.
3. Если известно имя — `fs_search` или `find /app -iname '*имя*'`; не обходить всё глазами.
4. Перед правкой прочитать файл и использовать абсолютный путь.
5. Новый долговечный файл класть в самый узкий подходящий дом; временный — в `workspace`, не в `/app`.

Мнемоника: **soul — кто я; memory — что помню; root — как работаю; workspace — что мастерю; Forge — где сейчас чиню.**
