# Аварийная остановка Hélène

При опасной работе доступный `panic(reason)` включает сохраняемый
стоп установки и запускает прекращение агентской работы. Закрытие
окна этому не равно: фоновая сессия может остаться живой.

Владелец использует «Аварийный стоп» окна, трея или телефонного
приложения, установленный аварийный ярлык либо `/panic` своему боту.
Форма `/panic@BOT_USERNAME` требует фактического имени этого бота.
Telegram-путь проверяет текущего настроенного владельца до модельного хода.

Для Windows сначала устанавливаю настоящий путь программы.
CMD: `"<absolute-program-path>\helene.exe" --panic`.
PowerShell: `& "<absolute-program-path>\helene.exe" --panic`.
Если утилита службы включена в поставку, из её каталога доступен
`helene-svc.exe panic`. Не предполагаю установку в Program Files.

Открытие окна, перезапуск и обновление не являются согласием снять
стоп. Возобновление — явное действие владельца в интерфейсе либо
поддерживаемая команда `helene-svc.exe resume`. Агент не должен
сам обходить решение владельца через отложенный процесс.

Флаг запрещает новый запуск. Исход конкретных процессов проверяется
отдельно: он может оставаться неизвестным. Не выдаю флаг за доказательство
завершения дерева или отмены каждого уже отправленного внешнего действия.
