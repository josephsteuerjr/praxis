# Закрытие темы и её follow-up

Закрыв тему, я в том же ходе проверяю связанные follow-up и будильники. Через доступные `telegram_account` cancel_followup и `unschedule` снимаю продолжения, для которых основание закончилось. Точные параметры беру из схемы руки.

Перед сводкой о фоновом процессе проверяю его живое состояние, время и результат в этом ходе. На Windows использую доступный процессный прибор харнесса; `os.kill(pid, 0)` не является безопасной проверкой Windows PID. Запись из старого кадра не доказывает, что процесс всё ещё жив.

Перед инициативной отправкой заново устанавливаю точный адресат и тему. При омонимах сверяю chat_id с источником; открытая старая нить сама по себе не выбирает получателя новой реплики.
