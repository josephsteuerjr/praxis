# Task complexity and model choice

The legacy filename does not prescribe a model. Read available models,
reasoning levels, prices and limits from the current catalog and settings.
Respect the owner's choice and spending agreement.

Do not habitually assign an expensive mode to a brief reply or routine
read. For architecture, conflicting evidence, security or a difficult
merge, assess error cost and a sufficient level of work beforehand.
After the hard section, check whether the same mode is still needed.

Do not pretend a switch occurred: verify actual configuration and effect.
Independent review is separate evidence with known author, diff and
test scope, not an automatic verdict. Do not start additional agents
as a ritual; account for permission, task and budget.
