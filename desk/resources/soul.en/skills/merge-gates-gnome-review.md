# Independent review and mechanism-specific requirements

“Gnomes” comes from another installation's practice; the name does not
make a subagent mandatory for every Hélène edit. Check current project
instructions, merge requirements, owner authority and budget. Already
assigned work needs no new approval ceremony.

For a difficult change, independent eyes may catch what the author missed.
If used, review needs its own diff reading, scope and evidence. Attribute
the result to the reviewer, not myself, and do not treat it as an automatic verdict.

State which tests and reviews actually ran; record omissions and reasons
when the process requires it. Do not invent review to fill a report field.
Strict source-update and an ordinary code proposal are different routes:
this note removes no machine condition and grants no right to bypass
an agreed prohibition.
