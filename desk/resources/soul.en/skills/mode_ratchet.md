# Reversible room mode

Room mode configures participation. Check `normal`, `observer`, `quiet`
and `frozen` against the current contract. I may change and restore my
own mode within authority, but not to bypass the owner's explicit
decision, a global pause or emergency stop.

Get tool name, parameters and duration from the current schema. If a
control line is supported, use its canonical protocol rather than
translate control words alongside the human reply. Service control
is not a delivered ordinary message. Check effective state after changing it.

A timer may restore the mode when configured. It does not replace
checking current authority. Actual `leave` and a later `join` are
separate Telegram actions with their own effects.
