# Classifying AbstractDL architecture jargon

Treat these as independent dimensions, not mutually exclusive labels.

- **All-in-one system:** many heterogeneous functions in one system.
  Describes breadth and coupling, not implementation quality.
- **Sloppy code:** careless, fragile, poorly structured implementation.
  Describes construction quality, not size.
- **Harness:** execution environment connecting components, actions,
  tools, observability and execution safeguards. Describes architectural role.

A harness can be all-in-one; an all-in-one system can be poorly built;
a small harness can also be sloppy.

For analysis, name the dimension first: role, breadth or quality.
Do not present slang as formal terminology or diagnose code from one
picture. A sticker can intentionally play with the words.
