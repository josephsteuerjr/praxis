# Follow-up threads after topic closure

An old follow-up can outlive the decision to close a topic. Match related
IDs, goal and current decision, then cancel obsolete continuations with
available `telegram_account cancel_followup` and `unschedule` under current
schemas. Do not cancel unrelated tasks through one broad keyword.

Before a process summary, obtain current platform-appropriate status,
generation and ownership. An old “alive” entry or CPU count is not
today's measurement. Unknown means neither absent nor confirmed active.

For new delivery, establish destination and topic again. A shared name
does not select a recipient: check exact chat_id and source, using
`recent_turns` if needed. An old live thread does not authorize a new
message. Record cancellations, checks and remaining unknowns.
