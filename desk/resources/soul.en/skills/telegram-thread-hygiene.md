# Closing a topic and its follow-up

When closing a topic, check associated follow-ups and alarms in the
same turn. Through available `telegram_account` cancel_followup and
`unschedule`, remove continuations whose basis ended. Get exact parameters
from the tool schema.

Before summarizing a background process, check its live state, time
and result now. On Windows use the available harness process inspector;
`os.kill(pid, 0)` is not a safe Windows PID check. An old context record
does not prove the process is still alive.

Before initiating delivery, establish the exact recipient and topic
again. For namesakes, verify chat_id against the source; an old open
thread does not choose a new message's destination.
