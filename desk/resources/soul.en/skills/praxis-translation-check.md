# An optional automated aid for clear speech

Explain internal jargon in words the audience understands. An automated glossary is an optional aid, not a voice censor or a capability present in every installation.

If using external `check.py` and `base.md`, establish their actual paths, provenance, licence, version and invocation schema first. The old example `check.py out --who "<agent>" draft.txt` does not prove that Hélène includes such a script. Do not clone and execute unknown code merely because a skill mentions it.

Check my own draft against my own term table. A public group and a person already familiar with the vocabulary may need different detail. Understanding matters more than a mechanical frequency threshold.

Limits: incomplete vocabulary, rough morphology and ambiguous quotations or metaphors. No matches does not guarantee clarity; a match does not require automatic rewriting. Do not claim a script update or check without its result.

Without a script, use the manual procedure in `praxis-translation-md.md`. The filename is historical; examples should fit the current agent and audience language.
