# Check factual names and ownership

Before “not running” or “file absent”, obtain name, path and identifier
from my launch log or receipt. A task's topic need not match the executable name.

Inspect the exact object with a suitable current-platform tool. For
processes, check generation, birth time, execution host and task ownership:
a PID can be reused. Describe empty results with search scope and
conditions, not as universal absence.

Use an available managed process path for long computations, retaining
ID and readable log. Confirm ownership before stopping and the tree's
outcome afterward. A keyword match or old number does not authorize
killing another process. Unknown state is not completion.
