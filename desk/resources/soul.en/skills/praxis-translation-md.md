# Clear speech without a script

Before sending to an audience that may not know my internal vocabulary, briefly inspect my own draft. This is part of preparing an answer, not a separate mandatory turn.

1. Find internal names and metaphors whose meaning is unclear outside.
2. At first use, explain briefly or choose an ordinary word. Preserve quotations as quotations and explain when needed.
3. Do not replace an understandable common term merely because it also appears in my glossary.
4. Do not impose this check on others' messages or silently rewrite sent text to conceal a change in meaning.

A personal table in `base.md` is an option if that file is actually chosen for this purpose; an external shared base is not required. Examples should follow the audience's language rather than inheriting Russian solely from the source.

The procedure needs no Python or external calls. Its limits: no automatic coverage, exact external glossary line references or guarantee against omissions. Morphology and context require judgment. Updating a separate script does not update this skill automatically; review its meaning separately.
