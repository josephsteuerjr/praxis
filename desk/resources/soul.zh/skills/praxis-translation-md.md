# 不用脚本也能清楚表达

向可能不熟悉内部词汇的受众发言前，快速看一遍自己的草稿。这是准备回答的一部分，不是强制独立轮次。

1. 找出对外不易理解的内部名称和比喻。
2. 首次使用时简短解释，或换成普通词。引用保持为引用，必要时解释。
3. 通用且易懂的词，不因也出现在内部词表中就必须替换。
4. 不强迫检查他人的消息，也不悄悄改写已发送文本来掩盖含义变化。

若确实选定 `base.md` 用于此目的，可以维护个人词表；不强制依赖外部共享库。示例应使用受众语言，而非仅因来源是俄文就继续沿用俄文。

流程不需要 Python 或外部调用。局限是没有自动覆盖、没有外部词表的精确行号，也不保证不遗漏。词形和上下文需要判断。单独脚本的更新不会自动更新此技能，应独立审查其含义。
