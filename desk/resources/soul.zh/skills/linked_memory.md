# 关联记忆

关联帮助找回相关事实，不是为收集社交图谱而收集。
每条关系都要核实来源、时效和访问范围。

`remember(person, fact, visibility=..., relates_to=..., relation=...)`
可按当前模式保存事实和关系。根据授权及内容明确选择可见性，不能默认全部公开。
`connections(name)` 显示可访问关联，`connections(name, to=...)`
可能返回链条，但链条不能证明其中所有人相互认识。

关系描述应简短、有来源，区分人物陈述与已验证事实。
无任务需要时，不盘问私人关系。不能把日记或摘要提取自动当真，派生地图不代替原记录。

不保证每个房间都能访问完整图谱。读取和披露分别核实，
记忆中有关系，不授权向当前受众公开他人的私人信息。
