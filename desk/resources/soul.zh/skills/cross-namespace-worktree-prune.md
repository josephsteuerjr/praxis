# Git worktree 与不同路径命名空间

主机和容器可能通过不同绝对路径看到同一仓库。
一边运行 `git worktree prune`，可能把另一边仍在使用的工作副本当成已丢失，
并删除其元数据。

清理前，在创建环境查看 `git worktree list --porcelain`，核实归属、
未提交和未跟踪文件，保留结果与原始修改。
只通过 `git worktree remove` 移除自己已完成的副本，
不能顺手全局清理其他副本或当前环境看不到的副本。

连接已断并出现 `not a git repository` 时，先保存代码树、diff 和校验值。
不盲目重建 `.git/worktrees/*`，也不能因元数据损坏就断言任务进程结束。
迁移到健康隔离和最终状态要按正式方式处理，保留旧历史及未知结果。
