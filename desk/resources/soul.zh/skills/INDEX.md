# 技能

这是初始技能库，不是个人经历清单。文本写于我诞生之前，可能包含其他
安装环境的示例。兼容性和权限以当前系统为准，笔记不能启用组件，也不能授予权限。

技能地址是文件名，翻译时保持不变。用 `fs_read soul/skills/<name>.md` 打开，
用 `recall` 搜索，用 `my_capabilities` 查看当前能力。
用途描述可以发展，不改变地址。第一天可先读 first-day 和 write-your-skills。
