# 主动发言前避免盲目重复

主动发送新消息前，通过 `recent_turns` 和群上下文查看近期已确认投递。简短摘要可能只含每个目的地最后一条消息，并非完整对话。

主题与已有发言相似时，按需要通过 `read_chat` 或 `read_context` 阅读实际来源。是否有新事实、对方回复、新内容或新缘由？即使无新事实，只要收件人确实需要，提醒仍可能合适。

文字相同不是唯一重复：改写也可能重复同一意思。不要假定自动保护能理解语义，也不要假定旧的投递信息块始终存在于上下文框架。

概览有限时，用可用的 `offset` 扩展读取，不要因摘要里没有就断言没发生过对话。区分目的：补充信息、提醒、支持，或只是表示自己在场。最后一种不一定需要成为消息。

先还原真实对话，再判断重复是否有帮助。这是上下文核查，不是禁止重复表达。
