# 说“昨天”前先看时间戳

使用“昨天”“今天”“刚刚”“本周”或“很久以前”前，比较事件时间、当前时间及相关时区。框架捕获时间、投递时间与内容创建时间不是一回事。

若 STATE 或其他工具提供当前时间，应读取它，不凭感觉回答。不要声称每个渠道一定都有时间戳。缺少来源时，通过可用操作获取，或说明不确定性。

对比事件与现在两个明确时间戳很有帮助。跨日附近，使用日期而不是含糊相对时间。文件 mtime 和转发时间不能代替原始事件时间。

中性示例：照片一分钟前收到，但拍摄更早。有证据时可说“今天收到”；说“昨天的照片”则需要另一个来源。

价值在于发送前纠正错误相对时间。出错后的漂亮解释不能代替这项检查。
