# 通过 Relay 使用 ChatGPT 订阅

这是一条连接流程，不是永久有效的版本快照。先确认产品、系统和版本：Hélène 内置 relay 与供 Ouroboros 使用的独立 praxis-relay，在管理和分发上不同。

Hélène 中使用订阅设置及应用提供的账号登录。不要为照搬旧菜单另装第二个 relay 或停止内置服务。菜单、支持构建和登录方式以当前应用为准。

独立客户端流程：

1. 核实现行官方版本和文档，下载匹配系统及架构的构建，不保证不存在的产物。
2. 通过可用 OAuth/device 流程登录自己的账号。不可分享凭据；是否需要外部 Python 取决于版本，不作通用要求。
3. 启动 relay，并在客户端使用期间保持运行。
4. Ouroboros 中选择受支持的 OpenAI-compatible 提供方与真实本地 base URL。`http://127.0.0.1:5011/v1` 是独立 relay 默认地址示例，不是其他电脑的地址，也不是 Hélène 设置保证。
5. 按客户端/relay 核实密钥要求及模型前缀。不要拿另一个有效令牌充当装饰字符串。用 `/v1/models` 核对可用模型，而非旧名称列表。

需要时诊断：`/health` 检查本地服务器，`/v1/limits` 提供可获得的额度信息。健康状态不证明提供方已接受请求。额度耗尽时，受支持的已授权账号切换可能有用，但不能重放部分完成的请求，也不能承诺无限容量。全部合适额度耗尽时，说明原因及已知恢复时间。

停止前区分自己的独立进程、应用 relay 与其他服务。通过受支持流程撤销访问，不凭旧路径随意删除 auth 目录。

它是连接自己 ChatGPT 账号的非官方桥接，不是 OpenAI API 账号，也不能把 Claude 订阅变成 Anthropic API。套餐和上游行为可能变化，帮助他人时应核查当前一手来源。
