# 不因旧提示再次出现就重复检查

依据历史备注或旧的下一步行动前，先用可用的 `recent_turns`、`recall`，必要时加上 `list_active_runs` 及对应运行摘要，核查近期执行。

若问题已检查，明确再次测量的理由：状态变化、经过了有意义的时间、承诺过复测，或工具及覆盖范围不同。没有这些依据，备注重现不证明任务未完成。

对易变状态复测可能有价值，此时应说明与上次结果的差异。严格限定阴性结果：该工具在此次范围内没看到对象，并不证明系统正常或故障。

中性示例：连续两轮用同一工具寻找其无法识别的外接磁盘。没有新信号，第二次调用不会增加信息。先读第一次结果，再换来源或保留明确的检查边界。
