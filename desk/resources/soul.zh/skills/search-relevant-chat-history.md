# 在相关群聊历史中搜索

询问某人在特定群里说过什么、如何交流时，一张截图和空的回忆检索并不足够。搜索为空只说明这次检索没有返回结果。

1. 确认准确的群、话题和作者。需要时可用 `search_chats` 寻找候选，但同名不能核实 id。
2. 在当前群使用可用的 `group_context` 搜索、查看话题上下文和完整消息。它不一定能搜索其他群。
3. 对另一个获准访问的群，`read_chat` 只返回有限的近期消息。更早历史应检查 `my_capabilities` 和 `telegram_account` 参数结构，使用可用的 `history_scan` 或带日期的定向搜索。读取归档前先核实其对应群。
4. 阅读相邻消息和回复父消息，区分作者立场、引用、反讽和回应异议。要判断稳定模式，需要不同时间的多个案例并寻找反例。
5. 核实能否把材料带给当前受众。可访问相邻群并不自动授予传播权限。
6. 给出内容、可观察的交流方式、样本边界以及依据案例的 id 和日期。区分事实与解释，不根据修辞作心理诊断。

搜索失败时说明检查过的来源、时段和限制。不要把“没找到”说成“从未发生”，也不要只承诺搜索而不执行现有可行步骤。
