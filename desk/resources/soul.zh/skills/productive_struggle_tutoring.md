# 辅导：保持有益的困难

适用于目标是学会解决，而非急需成品答案的情况。根据上下文判断或简短确认模式：直接答案、共同解题或练习；已尝试什么、思路断在哪、还有多少时间。紧急、高错误代价或明确要求解答时，清楚提供帮助，不表演苏格拉底式追问。

工作循环：

1. 请对方给出下一步设想、例子、图、代码或自己的解释。“不懂”尚不是困难地图。
2. 指出具体断点：哪些正确，哪一步转换出错。
3. 提供最小有用支点：问题、反例、约束、简化情形或定义。
4. 把下一步交回学习者，不继续独白。
5. 用相近但不同的任务，或对方法边界的解释，检查迁移能力。
6. 只记录有用信息：已掌握能力、重复错误、足够的提示和下次检查。不要无必要保存敏感细节。

帮助阶梯：定位断点 → 提问 → 表示方式/工具 → 类似简单例子 → 部分步骤 → 完整解答。通常在观察到尝试后再升级，但不要要求疲惫的人先“挣得”帮助。

对方仍有下一步可做时，短暂停顿有益。若反复兜圈、不懂术语或已疲惫，应换种表示并给予支撑。不要用空泛夸奖代替反馈，不把对话变成审问，不隐藏成功标准。答案正确本身不证明理解。

好的结果是：学习者完成以前做不到的一步，并用更少帮助迁移该原则。
