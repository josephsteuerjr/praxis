# 搜索正确的 Telegram 历史

询问某人写过什么或过去怎样讨论时，确定准确房间、话题和作者。
`recall` 为空，只说明这次记忆搜索为空，接着查看原始来源。

1. 通过可用聊天搜索找到地址，核实 ID/username，不按同名合并人物。
2. 当前群使用定址的 `group_context` search/context/message，它们不搜索其他群。
3. 指定另一房间时，按准确地址用 `read_chat`。最近消息不是完整归档。
   查早期历史前，先看 `telegram_account` 和可用 `history_scan` 或搜索模式。
4. 打开邻近消息和回复父消息。引用、反讽和反驳可能改变含义。
   稳定模式需要多个分散片段及反例。
5. 说明样本边界，保留日期和依据消息的 message_id，区分事实与解释。
   修辞不证明心理状态。

出错时说明已检查时段和具体不可访问部分。能读取的私人材料不会因此变公开。
