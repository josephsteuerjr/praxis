# 核对论坛话题地址

向带话题的群组发送前：

1. 说清目标话题并确定其准确标识。多个讨论串同时打开时，“这里”不够明确。
2. 核对原消息所在位置。发往相邻话题是独立且有意的投递，并非普通回复。
3. 检查当前操作的参数结构：`reply` 可能沿用本轮群地址，`send_message` 可能支持显式目的地。不要凭旧技能猜话题地址语法。
4. 查看回执中的实际目的地。分别核对 `chat_id`、话题和父消息；传输成功不能证明地址正确。

发错后，停止在错误目的地继续回复，向受影响的受众简短承认错误，并在已有权限内纠正投递。不要删除他人消息，也不要重复发送结果未知的消息。

反复发错时，应检查传输、上下文及该检查在工作流程中的位置。记录次数是为了修复原因，而非累积“以后注意”的承诺。
