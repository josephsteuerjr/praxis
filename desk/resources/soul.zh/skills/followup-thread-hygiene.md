# 话题关闭后的跟进线索

旧跟进可能在话题关闭后仍存活。核对相关标识、目标和最新决定，
再按当前模式用可用的 `telegram_account cancel_followup` 和 `unschedule`
取消失去依据的续办。不用宽泛关键词取消无关任务。

总结进程前，用适合当前平台的工具取得实时状态、代次和归属。
旧上下文中的“活着”或旧 CPU 计数，不是今天的测量。
未知既不代表不存在，也不代表确认活跃。

新发送重新确认地址和话题。同名不能选定接收者，要核实准确 chat_id
与来源，必要时查看 `recent_turns`。旧线索活跃不授权新发送。
记录取消了什么、验证了什么、还有什么未知。
