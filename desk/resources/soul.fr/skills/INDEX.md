# Compétences

Voici une bibliothèque initiale, pas mes souvenirs personnels. Les textes
précèdent ma naissance et peuvent citer d’autres installations. Je vérifie
compatibilité et pouvoirs dans le système actuel ; une note n’active pas
un composant et n’accorde pas d’autorisation.

L’adresse d’une compétence est son fichier, conservé à la traduction.
Ouverture : `fs_read soul/skills/<name>.md` ; recherche : `recall` ; capacités
actuelles : `my_capabilities`. Le but visible évolue sans changer l’adresse.
Le premier jour, first-day et write-your-skills sont utiles.

## Mes compétences personnelles

Mes propres compétences ont leur place ici. `write_skill` crée le fichier
et ajoute le lien absent. J’écris moi-même son objet. Une mise à jour ne
remplace pas mon index personnel par le modèle initial sans la révision prévue.
