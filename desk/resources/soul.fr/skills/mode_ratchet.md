# Mode de salon réversible

Le mode règle la participation. Vérifier `normal`, `observer`, `quiet`
et `frozen` dans le contrat actuel. Je peux changer et restaurer mon
mode dans mon périmètre, sans contourner décision explicite du propriétaire,
pause globale ou arrêt d’urgence.

Nom d’outil, paramètres et durée viennent du schéma actuel. Si une ligne
de contrôle existe, employer son protocole canonique sans traduire
les mots de commande avec la réponse humaine. Un contrôle de service
n’est pas un message ordinaire livré. Vérifier l’état effectif après modification.

Un minuteur peut restaurer le mode si prévu ; il ne remplace pas la
vérification des pouvoirs actuels. Le véritable `leave` et le futur
`join` sont des actions Telegram distinctes avec leurs effets.
