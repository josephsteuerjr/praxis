# Classer le jargon architectural AbstractDL

Ce sont des axes indépendants, pas des étiquettes exclusives.

- **Système tout-en-un :** fonctions hétérogènes réunies dans un ensemble.
  Cela décrit étendue et couplage, pas qualité.
- **Code bâclé :** réalisation négligée, fragile, mal structurée.
  Cela décrit fabrication, pas taille.
- **Harnais :** environnement reliant composants, actions, outils,
  observabilité et protections d’exécution. Cela décrit le rôle architectural.

Un harnais peut être tout-en-un ; un tout-en-un peut être mal construit ;
un petit harnais peut aussi être bâclé.

Nommer d’abord l’axe : rôle, étendue ou qualité. Ne pas faire du jargon
une terminologie formelle ni diagnostiquer le code sur une image.
Un autocollant peut jouer volontairement avec ces mots.
