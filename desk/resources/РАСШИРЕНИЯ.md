# Свои тулы и крючки: расширения (helene.ext/1)

С 0.8.7 свой тул или прибор для агента — не патч файлов программы, а **расширение**:
папка с манифестом и модулем в папке данных агента. Обновление программы папку данных
не трогает, поэтому расширение переживает обновление; если новая версия ему не подходит,
это видно словами до подмены папок, а не молчанием после.

## Куда класть

```
data/extensions/<имя>/
  extension.json      # манифест
  <имя>.py            # код: функция register(api)
  README.md           # зачем и как проверить (для владельца и для агента)
```

`<имя>` — латиница, цифры, `-` и `_`, до 40 знаков; имя в манифесте обязано совпадать с
папкой.

## Манифест `extension.json`

```json
{
  "name": "quota",
  "version": "1.2",
  "api": "helene.ext/1.0",
  "requires": {"helene": ">=0.8.7"},
  "entry": "quota:register",
  "capabilities": ["fs.read", "http"],
  "acceptance": "quota:check"
}
```

- `api` — версия API расширений, под которую написан код. **Major обязан совпасть с
  программой, minor — минимум, который расширению нужен.** Внутри major программа только
  добавляет; ломающая правка — новый major, и расширение отказывается словами при
  загрузке («написано под helene.ext/1.0, движок даёт 2.0 — адаптировать»).
- `requires.helene` — необязательно: `">=0.8.7"`, `"0.8.7"` или `"*"`.
- `entry` — `модуль:функция`; модуль лежит в папке расширения.
- `capabilities` — что расширению нужно: `fs.read`, `fs.write`, `http`, `shell`,
  `journal`, `agent`. Тул, которому нужна необъявленная — не подключится.
- `acceptance` — необязательная проверка совместимости `модуль:функция(api)`: вернула
  `True`/`None`/`"ok"` — расширение живо; иначе строка — причина отказа.

## Код

```python
# data/extensions/quota/quota.py
QUOTA_TOOL = {
    "description": "Сколько запросов к модели осталось сегодня и когда обновится окно.",
    "input_schema": {"type": "object", "properties": {}, "required": []},
}

def tool_quota() -> str:
    return "сегодня: 143 запроса, окно обновится в 00:00"

def register(api):
    api.register_tool("quota", QUOTA_TOOL, tool_quota,
                      purpose="остаток запросов к модели за день", capabilities=("fs.read",))
    api.register_hook("after_turn", lambda chat_id, envelope: api.log(f"ход в {chat_id} закончен"))

def check(api):
    return True
```

Что даёт `api` (поверхность `helene.ext/1.0`):

| метод | что делает |
|---|---|
| `register_tool(name, schema, fn, *, purpose="", capabilities=())` | тул встаёт в общий список рук агента; в описании — пометка «(расширение quota 1.2)»; имя, занятое штатной рукой, получает вид `ext.quota.<имя>`; бюджет схем 30 000 знаков считается вместе со штатными, при переполнении тул не подключается, причина — в карточке |
| `register_hook(event, fn)` | крючки движка: `on_boot(api)`, `before_turn(chat_id)`, `after_turn(chat_id, envelope)`, `on_delivery(chat_id, item, receipt)`; сбой крючка — в журнал, ход продолжается |
| `agent()` | модуль дерева агента — читать атрибуты; `None` на репетиции |
| `tree()` | папка данных агента |
| `config()` | `helene.json` без секретов (ключи с key/token/secret/password скрыты) |
| `journal(text)` | запись в дневник агента от имени расширения |
| `log(text)` | строка в `helene.log` |
| `receipt(**fields)` | расписка тула в общем виде (JSON одной строкой) |
| `version()` | `{"api": "helene.ext/1.0", "helene": "<версия программы>"}` |

Регистрация закрыта после возврата `register()`: поздний вызов отказывает, а не
исполняется.

## Как это переживает обновление

1. **Загрузка.** Движок читает манифесты после подъёма тела и имён; сбой одного
   расширения не роняет остальные и не роняет ход. Причина — в `helene.log`, в снимке
   `memory/.state/extensions.json`, в карточке **Настройки → Расширения** и строкой в
   ориентире хода: агент видит «расширение quota не загружено: …», а не исчезновение
   тула.
2. **Репетиция.** Установщик обновления запускает `runner.py --check-extensions` питоном
   **новой** поставки против папки данных ДО снятия службы и подмены папок: версия API,
   `requires`, импорт кода, регистрация вхолостую, `acceptance`. Отчёт —
   `extensions-check.json` в корне установки (карточка его показывает).
3. **Отказ словами.** Хоть одно расширение не грузится — установщик останавливается,
   старая версия остаётся живой. Дальше три пути: **поручить агенту адаптировать**
   (кнопка в карточке: агент получает записку с фактами — папка, манифест, ошибка,
   версии API — переписывает под новый API или переносит патч и показывает дифф;
   подмена — только после твоего «да»); **обновить без него** (галочка «Обновлять, даже
   если мои расширения не пройдут проверку» у кнопки «Скачать и установить»); или не
   обновляться пока.
4. **Проверка руками.** `runtime\python.exe app\localharness\runner.py --check-extensions
   --data data` из папки программы печатает тот же отчёт.

## Что расширение НЕ может

Менять штатные руки и тексты кадра, читать ключи из `helene.json`, обходить ограду:
тул расширения — такая же рука, как штатные, и ходит под теми же правилами. Свой полный
`runner.py` по-прежнему возможен (как раньше), но обновления штатного движка в него не
приезжают — окно об этом скажет.
