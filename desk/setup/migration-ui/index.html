Где будет жить приложение

После подтверждения мастер остановит только выбранную прежнюю установку, сохранит данные, исходники и Git. После проверки нового окна он заменит ярлыки и удалит лишь неизменённые файлы прежней программы.

Продолжить попытку из другой папки
Если папка программы не менялась, журнал найдётся сам. Здесь можно явно выбрать сохранённую неудачную попытку; её данные сначала сверятся с текущей старой установкой.

Расширения — по выбору

Базовый путь — CPU. CUDA требует совместимой видеокарты и отдельного runtime; веса модели не нужно скачивать повторно.

Прерванный перенос продолжится по своему журналу. Чужая непустая папка не будет перезаписана. Stop и пауза агента сохраняются. Возврат к версии старее 1.9 потребует её переустановки; для системной установки Windows отдельно запросит права.
