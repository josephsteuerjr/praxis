# Вложения и обновление: путь пользователя

07.10.2026, кандидат 1.4.1. Оформление использует существующие бумагу, шрифты,
акцент, движение и reduced-motion. Оттяжка и физика ленты не меняются.

Картинка занимает устойчивый отпечаток, вписывается целиком и открывается внутри
приложения. Авторизованный HTTP fetch создаёт blob URL: исходная политика Windows
WebView `img-src self/data/blob` сохраняется. Есть загрузка, отказ с повтором,
увеличение, вписывание и 100%. Escape/закрытие возвращает фокус к исходной кнопке.
Невидимые отпечатки освобождают ссылки; неиспользуемые blob URL отзываются.

Сохранение спрашивает папку и имя. Развёрнутый диалог — собственный, с местами,
поиском, навигацией, клавиатурой, выбранными файлами и отменой. Совпадение имени
не заменяет файл молча. Запись временного файла завершается атомарным переносом;
расписка появляется после записи. Сохраняются просмотренные байты. Документы не
ограничены возможностью зрительного чтения. Paste/drop и лимиты16×64МиБ,
128МиБ суммарно сохраняются.

Файловый доступ окна выполняется его локальной оболочкой, в том числе при
удалённом агенте. Компьютер сервера не подменяет компьютер человека. Для прежней
локальной Windows-оболочки предусмотрен owner/local API; SYSTEM-служба выполняет
операции под токеном интерактивного пользователя. Этот API запрещён устройствам,
удалённым клиентам и серверной установке. В обычном браузере/на телефоне доступ к
папкам отсутствует: собственная форма спрашивает имя, затем явно передаёт файл
загрузкам браузера и не обещает непроверенный путь на диске.

Установщик начинает с собственного кадра подготовки, без «Далее» до определения
маршрута. Обновление имеет отдельный лист: текущая версия, чтение её решений,
прогресс, отмена/ошибка/результат. Отказ чтения предлагает повтор и возврат,
не переводит в первое конфигурирование. Закрытие во время операции сохраняет
возможность отмены и дожидается результата. Настроенные tree/code и текущая
конституция читаются из фактического дерева и переживают обновление.

Проверено адресно: installed Windows видит существующую картинку, открывает её,
сохраняет точную копию и добавляет обычный документ в черновик. Без новой генерации
и отправки сообщений. Изолированный browser preview подтверждает просмотр,
zoom, сохранение, конфликт имени, фокус и отдельный маршрут обновления с отказом
и отменой. Узкие Python/native проверки подтверждают атомарность, байты, лимиты
и ограничения доступа. Это не приёмка реального обновления установки или GUI
Linux/macOS; публикация и macOS CI — отдельные действия.
