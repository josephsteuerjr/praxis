## Сделано с репозиторием (03.09, чтобы не искать потом)

- Локальная ветка `history-private` вынесена из этого репозитория: она лежала
  здесь рядом с `origin`, настроенным на публичный GitHub, и один
  `git push --all` опубликовал бы её целиком, а в её истории есть адреса
  машины владельца, которым в публичном репозитории не место. Ветка сохранена
  полностью и удалена отсюда:
  * копия — `..\helene-history-private.bundle` (рядом с папкой `desk`, вне
    репозитория; проверено клонированием — история восстанавливается целиком);
  * вернуть при надобности:
    `git fetch ..\helene-history-private.bundle history-private:history-private`;
  * заодно `git config --local remote.origin.push refs/heads/main` — теперь
    голый `git push` отправляет только `main`.
  Осторожно: `git push --all` и `git push origin <ветка>` этот запрет обходят —
