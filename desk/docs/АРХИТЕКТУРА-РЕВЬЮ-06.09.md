## 4. Дубли кода Rust ↔ Rust (23 пары, главные)

[=] совпадает, [~] расходится поведением.

1. decode_config [=] shell ↔ svc (в setup не было — починено).
2. system_root/sys_exe [=] ×3; powershell_exe [=] ×2.
3. console_text/cp866 [~] ×3 — таблицы равны, комментарии противоречат друг другу о причине несведения.
4. **ps_quote [~ опасно]**: shell возвращает `'…'` с удвоенным апострофом, install.rs только удваивает — одно имя, два контракта.
5. job-объект [~] shell ↔ svc.
6. **random_hex [~ опасно]**: shell/svc — BCryptGenRandom; install.rs — RandomState+время (не CSPRNG), и именно им генерится ключ реле `sk-frame-…`.
7. Токен трубы: путь, проверка «16..128 alnum», ensure — по три копии.
8. spawn_child [~], ротация логов детей — три рецепта плюс `log_line` без ротации.
9. Проба порта/держателя: одна логика, два HTTP-клиента (ureq ↔ ручной HTTP/1.1 по TcpStream).
10. spawn_relay [~ поведение]: shell проверяет занятость порта и ставит RELAY_INSTRUCTIONS; svc — нет (второе починено).
11. Вход в ChatGPT: LOGIN/relay_abort/relay_login/relay_status — shell ↔ install.rs.
12. **probe_model [~ поведение]**: при 200 без списка моделей окно отвечает ok, установщик — не ok (случай z.ai). Один ключ проверяется по-разному в двух местах продукта.
13. service_state: с дедлайном 15 с (shell) и без (install).
14. Три рецепта повышения прав; shell install_service/remove_service результат не читают («запрошено» = успех).
15. Имя правила брандмауэра собрано руками в install.rs мимо `firewall_rule_title`.
16. Ярлык Пуск/AUMID — оба пишут ps1 в %TEMP%; известные папки — реестр (shell) против склейки `%APPDATA%` (install).
17. Три формата времени: helene.log — unix-секунды; service.log/broker.log — местное с секундами; broker.py — местное без секунд.
18. Разбор просьбы агента: shell частично повторяет `BrokerAsk::parse`, потом зовёт его (осознанно); broker.py — питоновский двойник, сверяется тестом.

## 5. Две трубы: deskapp/deskd ↔ transport/botapi

По записи не пересекаются: deskapp пишет только `desk_inbox/*.md`,
`.state/devices.json` и маркдауны через readers; transport/botapi — только
архивы комнат и реестр `group_context`. Пересечения по чтению:
`groups/*.jsonl`, `group_context`, `turns.jsonl`, `.reader.json`,
`anatomy.json`, `body.json`.

Слабые места:

- `_append_jsonl` без замка (transport.py:34-37): long-poll бота и главный
  поток дописывают один `groups/<chat>.jsonl` — склейка строки возможна.
- Реестр `group_context`: read-modify-write вне замка — счётчик отстаёт на
  единицу (косметика).
- **Анатомия устаревает**: `anatomy.json` пишется один раз на старте, а просьбы
  агента о папках живут в памяти fence — карточка «Монтирование» показывает
  их только после перезапуска; `computer_live` при этом едет живым через
  `body.json`. Две карточки одного экрана — разные правила свежести.
- `readers.py` в процессе трубы импортирует `modes` из папки харнесса через
  `sys.path` и ходит в SCM — труба перестаёт быть «только читателем файлов».
- deskapp: таблица маршрутов дублирована (HTTP и `_tunnel_dispatch`) — класс
  «ручка есть в одном канале из двух» уже случался (/api/home).

## 7. Решения на суд владельца

1. **Workspace + крейт `helene-common`** вместо `include!` — снимает ~12 пар
   дублей и запрет на Win32 в common; цена: правка путей target в
   build_dist.py, единый lock, `pub` в common.
2. **Реестр ключей `helene.json`** «ключ → владелец → кто читает» с
   тест-сверкой в три стороны (Rust/Python/TS, по образцу relay-url.test.mjs
   и vite-плагина); цена — документ и три маленьких теста.
3. **`config_save` с проверкой свежести** (mtime, 409 при расхождении, как у
   `safe_write_md`) — закрывает гонку окно ↔ руннер/установщик/Блокнот;
   15 строк Rust + 10 TS.
4. **Установщик не переписывает `model` целиком** — слить по полям, сохранив
   `keys`/`compact_model`.
5. **Ключ реле — из CSPRNG** (BCryptGenRandom, как в shell/svc); после п.1
   бесплатно.
6. **Один `probe_model`** и один `service_state` (с дедлайном) на окно и
   установщик; установщик правее в случае z.ai.
7. **Один рецепт повышения прав** для службы из окна (service_op из
   установщика), чтобы «запрошено» перестало значить «сделано».
8. **Форм-кит и `modes.json` в ui-kit** (§6, UI) — полдня правок.
9. **Живые просьбы о папках** — окно читает `.state/mounts.json`, а не
   анатомию; или руннер переписывает анатомию по событию.
10. **Замок на `_append_jsonl`** — три строки.
11. **Один формат времени** во всех журналах.
12. **Рез монолитов** — своей волной после 0.3.1, с зелёными стендами до и
    после, в порядке §6.
