# Реестр: тесты и тулы апдейта 1.2.9 (живой список, 01.10)

Правило (слово владельца): на каждую вещь этого апдейта фиксируем, какой тест
её держит и какой тул нужен агенту — добавлен, изменён или УДАЛЁН. Материал
может встречаться в нескольких местах (описка/камбек) — реестр и есть защита
от «приняли один раз, а приехало дважды»: у каждой вещи один канонический
тест и одно место правки. Обновлять при каждом изменении состава.

маленькая правка files.ts — при следующем UI-заходе).

## Тулы: сводка изменений состава за апдейт

- ДОБАВЛЕН `clear_owner_marks` (провенанс правок владельца).
- ИЗМЕНЁН поток без тулов: `_batch_files`/`_batch_images`/`_hear_attachments`
  — это руннер, не тулы модели.
- УДАЛЕНО: ничего. Кандидатов на удаление (по результату ревизии): нет —
  `write_skill` и правки души остаются; при переезде раскладки проверить,
  не остаётся ли тул, пишущий в PF-пути напрямую.

## Живые приёмки до выпуска (не автоматизируются здесь)

1. Установленный WebView: парковка файлов, sticky-плашки, полоски леджера
   на настоящих 5,5 ГБ, «Править» оставляет марку, агент убирает тулом.
2. Два голосовых + картинка + pdf во время реального tool-loop; следующий
   model input содержит слова, image-блоки (≤3 на anthropic-ноге), путь pdf
   в runs/<id>/files.
3. Кандидат собирается из ядра port-2409 (OWNER_INPUT_DRAIN), не из mirror.
