# Окно Праксис

Личное окно владельца к серверной Праксис для Windows: тонкая оболочка Electron, страница
приезжает с её сервера (`/assets/praxis-window/index.html`) — та же бумага и те же три
голоса, что у её телефона, разложенные для широкого экрана. Открыто на её канале только
ключом владельца: телефону эти маршруты не видны.

## Что умеет

- Разделы: **Сейчас** (как она, расход и лимиты, текущий ход, предыдущие ходы, субагенты,
  проверки оператора), **Чаты** (её комнаты и темы, лента, её ходы в комнате, написать ей),
  **Задачи** (намеченное, доска, Forge), **Пробуждения**, **Приборы** (разбор хода, её журналы,
  кэш и расход, тень), **Файлы** (её память и навыки, читать и править), **Система** (всё, чем
  владелец управляет с телефона, и само окно). Ctrl+1…7 — разделы.
- Полки сворачиваются, как в Элен, и помнят состояние: полка слева — **Ctrl+B**, панель хода
  справа — **Ctrl+J** (или кнопки по краям шапки). В «Чатах», «Файлах» и «Приборах» список
  слева сворачивается своей кнопкой — открытое справа остаётся на месте.
- **Ctrl+R / F5** — перечитать окно (раздел остаётся тем же). **Ctrl + колесо**, **Ctrl + «+» / «−» / «0»**
  или кнопки в «Система → Это окно» — масштаб страницы (60…160 %), запоминается.
- Открывается развёрнутым на весь экран; в обычном размере — по пропорциям экрана, запоминает
  положение. Повторный запуск (ярлык) поднимает открытое окно поверх остальных. Автозапуск
  вместе с Windows — переключателем в «Система → Это окно» (стартует свёрнутым).
- Оболочка сама сверяет размер страницы с окном: после смены экрана (удалённый рабочий стол
  подключился и отключился, монитор, масштаб) страница не остаётся размеченной под прежний
  размер. Журнал оболочки — `shell.log` в профиле.
- **Без скрипа.** Каждый раздел живёт в своём доме, пока окно открыто: после запуска все они
  готовятся за экраном по очереди, и щелчок по полке открывает уже готовый — с прежней позицией
  прокрутки и открытой комнатой. Опрашивает её сервер только раздел на экране; скрытые спят.
- **Без VPN.** Сервер может быть недоступен из страны напрямую; тогда окно ходит до него через
  местный прокси — SSH-туннель до машины с tinyproxy, его держит задача «Praxis Proxy».
  Дорога выбирается в «Система → Это окно»: авто (помнит, что сработало в прошлый раз), напрямую,
  через прокси. Тот же туннель выводит в сеть и тело Праксис (`praxis-body`).

## Как это устроено

Три голоса — из её набора (`remote/praxis-desk/desk/ui-kit`, бумажный слой): **почерк** (Zen Kurenaido) —
заголовки, **Golos Text** — текст и интерфейс, **моно** — только машинные метки. Цвета, карточки,
кнопки, шаги, лента и настройки — её готовые блоки (`phone-actions`, `usage`, `praxis-control`,
`praxis-service`, `praxis-voice`, `forgePanel`, `mountActionSteps`, `lookCard`), страница только
раскладывает их и добавляет то, чего телефону не нужно (полки, шапка раздела, списки, таблицы,
приборы). Шкала размеров — переменные `--t-*` в `ui/src/shell.css`; держать её не крупнее
телефона и окна Элен.

| Файл | Что в нём |
| --- | --- |
| `electron/main.cjs` | Вход: `--proxy-keeper` — хранитель туннеля, иначе окно. |
| `electron/window.cjs` | Оболочка: окно, вход по ключу, дорога до сервера (напрямую / прокси), задача «Praxis Proxy», повторный запуск, клавиши (Ctrl+R/F5, масштаб), сверка размера страницы, автозапуск, настройки. |
| `electron/preload.cjs` | Узкий мост между страницей и процессом (`praxisWindow`): изоляция контекста и песочница Chromium. |
| `electron/connect.html`, `connect.cjs` | Страница входа: подключается сохранённым ключом сама, без сети — говорит словами и пробует снова. |
| `electron/server.example.json` | Образец адреса сервера; свой адрес лежит рядом в `server.json` и в Git не входит. |
| `electron/proxy-config.cjs` | Настройки и состояние прокси (`%LOCALAPPDATA%\Praxis\DesktopWindow\proxy`): чтение, проверка, жив ли туннель. |
| `electron/proxy-keeper.cjs` | Хранитель туннеля: держит plink, перезапускает после обрыва, пишет `status.json`; по запросу — прозрачный выход для тела. |
| `proxy/install-proxy.ps1` | Настроить прокси: из `start_server_proxy.bat` или параметров; проверка подписи plink, пробный запуск. |
| `proxy/body-dial.ps1` | Вывести тело Праксис через тот же туннель (и `-Undo` — вернуть как было). |
| `ui/index.html` | Каркас: полка, шапка раздела, раздел, панель хода. |
| `ui/src/main.ts` | Дома разделов и подготовка за экраном, сворачивание полок, клавиши, масштаб колёсиком, состояние в localStorage. |
| `ui/src/core.ts` | Дорога к её каналу (`api`/`post`), ворота спящего раздела (`gate`/`lull`/`wake`), состояние Праксис, мост к оболочке, общие элементы. |
| `ui/src/shell.css`, `views.css` | Каркас окна и раскладка разделов. |
| `ui/src/views/*.ts` | Разделы: `now`, `chats`, `tasks`, `wakes`, `instruments*`, `files`, `system`; `runs.ts` — строки ходов. |
| `frontend.py` | Сборка страницы: её набор из Git (`RELEASE`, `KIT`) + `ui/` → `ui.zip`. |
| `build.ps1` | Оболочка Electron для Windows; `-Install` ставит в `%LOCALAPPDATA%\Programs\Praxis` и ярлыки. |
| `publish_ui.py` | Выкладка страницы на сервер (её `static/assets/praxis-window`). |
| `server/` | Серверная часть: `praxis_window.py` — читатель журналов харнесса для «Приборов» (только чтение, только владелец), его тест и сценарий подсоединения к каналу. |

### Адрес сервера

В исходнике адреса нет. Оболочка берёт его из `electron/server.json` (при сборке он уезжает
в `resources/app/server.json` рядом с программой), без него — из действующего подключения
PraxisPult, а без того честно говорит на странице входа, что адрес не задан:

```json
{ "server": "https://praxis.203.0.113.10.nip.io" }
```

Локальная разработка (`vite`) ходит на тот же адрес: её `/api` и `/pair` проксируются туда.

### Прокси без VPN

Хранитель — тот же приём, что «Helene Relay Proxy» у Джарвиса: `plink.exe` (только официальный,
с проверкой подписи PuTTY) открывает SSH-туннель до машины с tinyproxy, на этом компьютере
слушает `127.0.0.1:18890`. Ключ машины закреплён отпечатком: не совпал — хранитель
останавливается и не пробует снова. Пароль туннеля лежит в `config.json` (папка доступна только
владельцу и системе), файл для plink удаляется через несколько секунд после старта. Хранитель
переподнимает туннель после обрыва сети и пишет состояние в `status.json`. Задача «Praxis Proxy»
(скрытая, при входе владельца, перезапуск при сбое) заводится самим окном, переключателем
«Прокси без VPN» в «Система → Это окно».

```powershell
# настройки из батника проекта; окно и хранитель перезапускаются
pwsh -File .\desk\praxis-window\proxy\install-proxy.ps1 -Bat C:\path\to\start_server_proxy.bat -Dial
# телу Праксис — нужны права администратора (перезапускает его службу)
pwsh -File .\desk\praxis-window\proxy\body-dial.ps1 -Elevate
```

Тело о прокси не знает. С `-Dial` хранитель открывает прозрачный выход `127.0.0.1:443`:
всё, что туда пришло, уходит через туннель к серверу под его настоящим именем (TLS и WebSocket
без изменений). Телу остаётся набирать сначала этот адрес — `body-dial.ps1` дописывает его в
`dial_addresses` настроек тела (с правкой на месте и запасной копией прежних). Если туннель не
стоит, выход сбрасывает соединение сразу, и тело идёт напрямую, как прежде.

### Серверная часть

«Приборы» читают то, что харнесс уже записал: журнал хода (`memory/runs/…/events.jsonl`,
`context.md`, `RECAP.md`) и фиксированный список её журналов состояния под `memory/.state`.
Модуль `deskd/praxis_window.py` живёт в её серверном приложении (`/opt/praxisdesk/deskd/`,
источник — зеркало `remote/praxis-desk/`); `server/` здесь — копия развёрнутого. Подсоединяется
к каналу двумя строками после её же `praxis_phone` (`server/attach_to_channel.py`):

```python
from deskd import praxis_window
ROUTES += praxis_window.routes(Route)
```

Маршруты: `GET /api/window/journals`, `/api/window/journal/{name}`, `/api/window/run/{run_id}`,
`/api/window/run/{run_id}/frame`, `/api/window/run/{run_id}/doc/{name}`. Ничего не пишут,
для решений не используются; журналы с контактами, ключами и состоянием устройств в список
не входят.

## Собрать и выложить

Нужны Python 3.12+, Git, Node с npm, PowerShell. Сначала — `electron/server.json` со своим
адресом сервера (образец `server.example.json`).

```powershell
# страница + оболочка; -Install заменяет установленную программу и ярлыки (окно должно быть закрыто)
& .\desk\praxis-window\build.ps1 -OutputDir "$env:TEMP\praxis-window-build" -Install
```

```sh
python frontend.py <checkout> ui.zip        # страница (checkout — дерево с .git, где лежит remote/praxis-desk)
python publish_ui.py ui.zip /opt/praxisdesk/static   # на хосте интерфейса: новые ресурсы, страница — последней
```

Страницу можно обновлять без переустановки: «Система → Это окно → Обновить окно» или Ctrl+R.
Её канал и фронт телефона собираются из `remote/praxis-desk/`, а не из общего `desk/`.

Программа: `%LOCALAPPDATA%\Programs\Praxis`; профиль (ключ через safeStorage, настройки
`settings.json`, `shell.log`): `%LOCALAPPDATA%\Praxis\DesktopWindow\Electron`; прокси:
`%LOCALAPPDATA%\Praxis\DesktopWindow\proxy`. Ключ берётся из действующего подключения PraxisPult
или вводится владельцем.
