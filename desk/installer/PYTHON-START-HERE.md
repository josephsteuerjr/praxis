# Hélène 2.2.5

При обновлении с 2.1.1 старая кнопка может остановиться на совмещении кода
раньше запуска нового механизма. Распакуйте **новый** архив отдельно. В Windows
запустите `Prepare update.vbs` и выберите папку **уже установленной** Hélène
(с её `helene.json`). Подготовка совместит исходники и проведёт независимое ревью;
после сообщения о готовности вернитесь в старое окно и повторите «Обновить»
для **этого же выпуска 2.2.5**. Настройки, память и работающая программа на этапе
подготовки остаются на прежних путях. Если исходники или настройки изменятся,
подготовку потребуется повторить. Stop/Pause и отмена запрещают применение.

На macOS/Linux из нового распакованного комплекта:
`./runtime/bin/python3 -s app/python_update_prepare.py --old /путь/к/прежней/Helene`
(для явно выбранного браузерного наблюдателя добавьте `--browser`).
В новых версиях обычная кнопка сама выполняет подготовку до закрытия окна.

## Windows: первый вход и миграция

Запустите `helene-setup.exe`. Мастер нужен для новой установки и перехода старой
Hélène. Обычные последующие обновления запускайте из самой Hélène: Python
скачивает и проверяет пакет, сохраняет данные и код, обновляет рабочую папку,
подтверждает новый запуск и восстанавливает прежние файлы при неудаче. Выберите постоянную
папку программы, а не временную папку скачанного архива. `helene.exe` открывает
приложение; Python управляет его процессами. Привилегированный брокер не поставляется.

При новой установке настройте модель в окне программы. Архив не содержит чужих
ключей, аккаунтов или готовой конфигурации агента. При переносе сохраняются данные,
собственный код и Git; прежние файлы и восстановительные копии не удаляются
без подтверждённого запуска. Не закрывайте мастер во время переноса. Если шаг
завершился ошибкой, сохраните показанный журнал и повторите его после устранения
причины, не удаляя восстановительные каталоги.

Реле подписки запускается свёрнутым вместе с приложением; настройки управляют
тем же экземпляром. Смена модели и уровня рассуждения применяется к следующему
запросу без перезапуска реле. Вход, выход и выбор аккаунта доступны в настройках.

XTTS выбран по умолчанию, но загружается отдельно. Его модель распространяется
по CPML с ограничением некоммерческого использования. Whisper и инструменты
пересборки — независимые необязательные загрузки. Ни одна из них не нужна для
открытия окна. Наличие GPU не предполагается: используйте фактическую диагностику
выбранного голосового движка. Исходники реле лежат в `components/relay/source`.

Лицензия программы — `LICENSE`; сторонние условия —
`ЛИЦЕНЗИИ-ТРЕТЬИХ-СТОРОН.md` и `licenses/`. Эта Windows-поставка не является
подтверждением проверки установленного приложения на macOS или Linux.


## Linux: Python-приложение и локальный кандидат

В переносимом Linux-комплекте запускайте `./helene`, а не Windows EXE.
DEB/RPM `helene-python` содержит неизменяемый начальный комплект, значок и
`/usr/bin/helene`; службы, polkit и привилегированный брокер не устанавливаются.
При первом запуске обычным пользователем реальные файлы копируются в
`${XDG_DATA_HOME:-$HOME/.local/share}/helene-python/program`. Эта рабочая папка и
её родитель принадлежат пользователю: туда приходят штатные Python-обновления,
скачанные пакеты и восстановительные копии. Следующий запуск не накатывает
системный начальный комплект поверх самоправок. Удаление DEB/RPM не удаляет
пользовательскую папку, данные, код или Git. Версия системного начального
комплекта может отличаться от версии уже обновлённого приложения.

При первом Linux-запуске графический мастер предлагает нового агента или перенос
профиля до старта канала и агента. Его можно снова открыть командой
`./helene --migration-wizard` или из «Настройки → Перенос» (окно сначала закроет
своих детей). Выберите полную офлайн-копию, новую распакованную программу и
отдельную папку данных, подтвердите офлайн-источник и нажмите «Проверить».
Карта прежних абсолютных путей нужна только при смене адресов, например Windows
→ Linux. «Начать перенос» копирует память, настройки, выбранный код и Git;
исходник не удаляется. Агент запускается только отдельной кнопкой «Открыть
приложение». Если выбрана другая программа, откройте `helene` в её папке.
После обрыва мастер читает прежний журнал: проверьте те же пути и явно продолжите.

Перенос существующего профиля между ОС выполняется только с полной офлайн-копии.
`app/localharness/profile_paths.py --offline-copy OLD --new NEW --data-home HOME
--path-map MAP.json` принимает явную карту старых абсолютных Windows-путей к
папкам перенесённой копии. Не направляйте её в работающего агента. При обрыве
того же копирования используйте `--resume` с прежними путями и картой, не
удаляйте журнал. Подготовка профиля не подтверждает его запуск; исходная копия,
память, настройки, выбранный код, Git и попытки восстановления сохраняются.

Паспорт `local_candidate` обозначает частную проверочную сборку, не публичный
релиз. Необязательные голосовые/компиляторные компоненты выбираются по карте
конкретной ОС; отсутствие квалифицированного Linux-пакета показывается явно,
Windows-архив вместо него не скачивается. macOS arm64 не получает native PASS
по сборке или испытанию на Linux; её запуск, desktop permissions, подпись и
автозапуск требуют отдельного Mac-стенда.
