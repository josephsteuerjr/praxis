# Hélène 2.3.0

Распакуйте архив в постоянную папку. Python и готовая среда уже внутри.

- Windows: откройте **helene.exe**.
- macOS Apple silicon: откройте **Helene.app** в распакованной папке.
- Debian/Ubuntu и Fedora x86_64: запустите **Start Helene.sh** (при необходимости разрешите запуск файла).

Первый запуск автоматически подготавливает привязку к данным. Если агента
ещё нет, появится форма создания: можно выбрать конституцию Hélène или свой
текст либо файл.

В Windows каноническая папка данных — **%USERPROFILE%\Helene\data**. Запуск
проверяет сохранённую квитанцию и допустимые прежние размещения в ограниченной
области поиска. Подготовка автоматически подключает или переносит найденные
данные и удаляет признанные legacy-программы с проверкой их владения, остановки
процессов и сохранности данных. Это часть подготовки, а не универсальный
необязательный шаг после открытия нового окна. Современные папки с действующей
квитанцией защищены от legacy-очистки: пробный запуск другой папки сам по себе
не разрешает их удаление.

В macOS и Linux используется ранее допущенная привязка, а по умолчанию —
**~/Helene**. Другую папку данных можно подключить явно; обычный запуск
не удаляет прежнюю папку программы.

Обычная кнопка **Обновить** передаёт работу постоянному Python-хосту. Выберите
сохранение правок с совмещением, проверками и независимым ревью либо чистый код
выпуска с текущими данными. Первичная миграция следует своему предварительному
просмотру. Во время обновления окно может закрыться на несколько минут и
открыться автоматически; не запускайте другую копию программы.

Папку программы оставьте постоянной. Память, переписка, ключи и настройки
хранятся в подключённой папке данных. Не удаляйте папку программы целиком,
если внутри неё находится единственная копия данных агента.

Для явного восстановления или старой миграции доступен отдельный вход
**app/helene_setup.py** с комплектным Python. Это не обычный запуск ZIP-поставки:

Windows: `runtime\pythonw.exe -s app\helene_setup.py --root .`

macOS/Linux: `runtime/bin/python3 -s app/helene_setup.py --root .`

Кнопка **Вернуть код к upstream** рядом с обновлением восстанавливает чистый код
текущего выпуска и оставляет подключёнными текущие данные. Та же операция:
добавьте к команде мастера `--restore-upstream --confirmed`.

Whisper и XTTS — дополнительные загрузки в настройках. Apache, MIT реле
(включая unluckyjori) и отдельные условия XTTS находятся в **licenses/helene/**.
