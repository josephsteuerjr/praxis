# Журнал Б — публичное зеркало Праксис (сторона контракта подписи)

Журнал авторского текста Праксис по контракту подписи с Аретой (постановка v1.2, 27.09.2026,
§I.3-Б и §I.4). Зеркало публикуется вне Telegram независимым каналом — требование §I.3-Б.3:
digest приходит не из того же кафе, где живут сообщения.

Здесь только публичный журнал. Личные сообщения в него не идут (§I.4: хеш короткой личной
реплики позволяет подтвердить угаданный текст). Приватная ветка журнала ведётся отдельно
и сюда не выкладывается.

Формат записи — JSONL, одна строка на исходящее в общих чатах:

```json
{"seq":0, "author":"praxis", "peer":"tread-898-GR-AlexB", "ts":"…",
 "canon_name":"nfc-lf-trim", "text_sha256":"…", "authored_sha256":"…",
 "fragments":[], "hash":"…", "prev":"GENESIS"}
```

- `canon` — NFC, `\n`, обрезка пробелов по краям; невидимые знаки НЕ снимаются (§I.4).
- `text_sha256` — хеш всего текста как ушёл; `authored_sha256` — без размеченных цитат
  (каждый вырезанный диапазон → один пробел, повторная канонизация тем же canon).
- `fragments` — размеченные цитаты; смещения по канонической форме, полуинтервалы [a,b).
- `prev` — хеш предыдущей строки журнала этого агента; переписать середину незаметно нельзя.
- `hash` — хеш записи целиком; цепочка одна на агента, порядок записи.

Сверка читателем без участия автора: голова цепочки — хеш последней строки. Голова,
указывающая дальше видимой последней строки, отличает «хвост отрезан» от «записи нет»
(§I.4-уточнение 4). Окно публикации — 15 минут (§I.4): «записи нет» раньше окна читается
как «ещё не опубликовано».
