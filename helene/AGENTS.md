# Agent-context product text

Before changing prompts, tool explanations or helper captions, follow [the localization guide](../desk/docs/LOCALIZATION.md). New owned prose needs reviewed Russian, English, French and Chinese entries through the existing frame/schema/stock registries. Pin the frame language around a complete producer. Keep interface language independent from agent-context language.

Trace each new message to its actual display or model-context sink. Canonical protocol values, statuses, identifiers, hashes, commands, authored material and raw external evidence remain exact. Do not translate a data/control enum or infer success from a translated phrase. Use the producer's recorded outcome and preserve uncertainty and immutable history.

From the repository root, run `node desk/qa/localize.mjs check all` and the relevant existing behavioral checks. For a new surface, cover independent interface/context choices and real payload, receipt or effect preservation. Raw literals, dynamic keys and private-worker dependency boundaries still require review; catalog checks do not replace it. See the guide before adding a localization import to an isolated executor.
